# 🌤 Weather App

A simple and responsive Weather App built using **HTML, CSS, and JavaScript**. It allows users to search for any city and view real-time weather information using the WeatherAPI.

## 🚀 Features

- 🔍 Search weather by city name
- 🌡 Displays current temperature
- ☁ Shows weather condition
- 💧 Humidity information
- 🌬 Wind speed
- 🥵 Feels-like temperature
- 🕒 Local time of the searched city
- 🌤 Weather condition icon
- ⌨ Search using Enter key
- 📱 Responsive design

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- WeatherAPI

## ⚙️ How to Run

1. Clone the repository

```bash
git clone https://github.com/muskanraj8090/weather-app.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

4. Enter a city name and click **Search**.
